Pro Tips

Practices that make the automation stack reliable on Apple Silicon + dual monitors.

Golden rule: One pane for action, one pane for proof. Launch Terminal Ops (⌘⌃5), jump to the relevant tab, keep logs visible while you work.
⚡

Auto-reload on save

Any file change under ~/.hammerspoon/ reloads config via hs.pathwatcher. No restart needed.

📋

Clipboard safety

AI hotkeys restore your original clipboard after 2 seconds. Nothing auto-submits to ChatGPT — you always paste manually.

🖥

Hyper vs Mods

⌘⌃⌥⇧ = windows. ⌘⌃ = apps & utilities. ⌃⌥⌘ = AI. Muscle memory stays clean.

🐉

BlackDragon launch

⌘⌃1 finds the latest Xcode DerivedData build. From repo: ./launch.sh release.

👻

Ghostty config

Add to ~/.config/ghostty/config: config-file = {home}/.hammerspoon/scripts/ghostty/ghostty-terminal-ops-center.conf

🔧

Custom panes

Add pane_my-id() functions in your repo's .terminal-ops/pane.sh. BlackDragon already ships overrides.

🤖

Local AI

Tab 2 runs ollama serve. Shell: startai / stopai from ~/.zshrc. Pipe logs: cat err.log | ollama run llama3 "summarize"

🔗

n8n bridge

Run n8n on localhost:5678. Trigger from console: require('modules.n8n').trigger('hs/daily-log')

📐

layouts.lua = workspaces

Edit ~/.hammerspoon/modules/layouts.lua. Summon with ⌘⌃⇧1-4 or menu bar 🗂. Dump current screen with layouts.dumpScreen().

🪟

Hyper = quick snap

⌘⌃⌥⇧ arrows snap the focused window only. For full workspace restore, use Spencer — not Hyper keys.

🔄

Ops-center alias

ops-center in shell equals ⌘⌃5. Override project: TERMINAL_OPS_PROJECT_DIR=~/repo ops-center

📝

Project snapshots

⌃⌥⌘P writes a markdown snapshot to iCloud Obsidian — one file per minute, no duplicates.

🛠

Troubleshooting

Ghostty fails? Check Automation permission. Project missing? Verify ~/Documents/01_Projects/BlackDragon_Project exists.

When things break

SymptomFix
Hotkeys silentAccessibility → enable Hammerspoon → Reload Config
Ghostty won't openAutomation → Hammerspoon → Ghostty → Allow
Terminal Ops: project dir not foundCheck TERMINAL_OPS_PROJECT_DIR or clone project locally
AI: no text selectedHighlight text first; refocus app within 2s after hotkey
n8n HTTP errorStart n8n; confirm webhook path matches workflow
Layout wrong after applyIncrease placementPause in layouts.lua; run layouts.dumpScreen() to re-author positions
Dialogs get tiledAdd app to excludedApps or title pattern in windows.lua
Guide buttons no-opHammerspoon must be running; open guide via Safari not Chrome file:// quirks
